१. ऐतिहासिक पार्श्वभूमी (१६०० ते १७५७) — Deep Notes for Maharashtra PSI

१. भारतात युरोपियनांचे आगमन

भारतातील संपत्ती, मसाले, कापड, रेशीम आणि व्यापारामुळे युरोपियन राष्ट्र भारताकडे आकर्षित झाले.

समुद्री मार्गाचा शोध लागल्यानंतर अनेक युरोपियन भारतात आले.

  • पोर्तुगीज
  • डच
  • इंग्रज
  • फ्रेंच
  • डेन्मार्क

२. पोर्तुगीजांचे आगमन

भारतात सर्वप्रथम पोर्तुगीज आले.

  • भारताचा समुद्री मार्ग शोधणारा → वास्को-द-गामा
  • आगमन → १४९८
  • स्थळ → कालिकत (कोझिकोड)
  • कालिकतचा राजा → झामोरिन

पोर्तुगीजांनी पुढे गोवा, दमण, दीव येथे सत्ता निर्माण केली.

३. डचांचे आगमन

  • डच ईस्ट इंडिया कंपनी स्थापना → १६०२
  • मुख्य व्यापार → मसाले
  • मुख्य केंद्रे → पुलिकट, नागापट्टणम

डचांचा प्रभाव प्रामुख्याने इंडोनेशियात होता.

४. इंग्रजांचे आगमन (१६००)

इंग्लंडची राणी एलिझाबेथ-I हिने ३१ डिसेंबर १६०० रोजी ईस्ट इंडिया कंपनीला सनद (Royal Charter) दिली.

या सनदेमुळे कंपनीला पूर्वेकडील देशांशी व्यापार करण्याचा विशेष अधिकार मिळाला.

  • कंपनीचे पूर्ण नाव → Governor and Company of Merchants of London Trading into the East Indies
  • स्थापना → १६००
  • स्वरूप → व्यापारी संस्था

५. भारतात इंग्रजांचे पहिले आगमन

  • इंग्रज प्रथम भारतात आले → १६०८
  • स्थळ → सुरत
  • पहिला इंग्रज प्रतिनिधी → कॅप्टन विल्यम हॉकिन्स

विल्यम हॉकिन्स हा मुघल सम्राट जहांगिर यांच्या दरबारात गेला.

त्याला “इंग्लिश खान” ही पदवी देण्यात आली.

६. सर थॉमस रो यांचे आगमन (१६१५)

  • इंग्लंडचा राजदूत → सर थॉमस रो
  • भारत आगमन → १६१५
  • दरबार → जहांगिर

थॉमस रो याने इंग्रजांना व्यापारासाठी अनेक सवलती मिळवून दिल्या.

त्यामुळे भारतातील इंग्रज व्यापार मजबूत झाला.

७. इंग्रजांच्या प्रमुख वखारी

  • सुरत → पहिली वखार
  • मद्रास → फोर्ट सेंट जॉर्ज
  • मुंबई → पोर्तुगीजांकडून मिळाली
  • कलकत्ता → फोर्ट विल्यम

या वखारी पुढे इंग्रजांच्या राजकीय सत्तेची केंद्रे बनली.

८. मुंबई इंग्रजांना कशी मिळाली?

पोर्तुगालची राजकन्या कॅथरीन ऑफ ब्रागांझा हिचा विवाह इंग्लंडचा राजा चार्ल्स-II याच्याशी झाला.

त्यावेळी पोर्तुगीजांनी मुंबई हुंडा म्हणून इंग्लंडला दिली.

  • मुंबई इंग्लंडला मिळाली → १६६१
  • ईस्ट इंडिया कंपनीला भाड्याने दिली → १६६८

९. कलकत्त्याची स्थापना

  • संस्थापक → जॉब चार्नॉक
  • स्थापना → १६९०

पुढे कलकत्ता हे ब्रिटिश भारताची राजधानी बनले.

१०. फर्रुखसियरचा फर्मान (१७१७)

मुघल सम्राट फर्रुखसियर याने इंग्रजांना व्यापारासाठी विशेष सवलती दिल्या.

  • बंगालमध्ये करमुक्त व्यापार
  • दस्तक प्रणाली

या फर्मानाला “Magna Carta of East India Company” म्हणतात.

११. कर्नाटक युद्धे

भारतात इंग्रज आणि फ्रेंच यांच्यात सत्ता मिळवण्यासाठी युद्धे झाली.

  • एकूण युद्धे → ३
  • कालावधी → १७४६ ते १७६३

परिणाम:

  • फ्रेंचांचा प्रभाव कमी झाला
  • इंग्रजांचे वर्चस्व वाढले

१२. प्लासीची लढाई (१७५७)

२३ जून १७५७ रोजी प्लासी येथे इंग्रज आणि बंगालचा नवाब सिराज-उद-दौला यांच्यात युद्ध झाले.

  • इंग्रज सेनापती → रॉबर्ट क्लाईव्ह
  • विश्वासघात करणारा सेनापती → मीर जाफर

परिणाम:

  • बंगालवर इंग्रजांचे नियंत्रण
  • भारतातील ब्रिटिश राजकीय सत्तेची सुरुवात
  • ईस्ट इंडिया कंपनी व्यापारी संस्थेतून राजकीय शक्ती बनली

• १४९८ → वास्को-द-गामा भारतात

• १६०० → ईस्ट इंडिया कंपनी स्थापना

• १६०२ → डच ईस्ट इंडिया कंपनी

• १६०८ → विल्यम हॉकिन्स सुरत येथे

• १६१५ → सर थॉमस रो भारतात

• १६६१ → मुंबई इंग्लंडला मिळाली

• १६६८ → मुंबई कंपनीला भाड्याने

• १६९० → कलकत्ता स्थापना

• १७१७ → फर्रुखसियर फर्मान

• १७४६-६३ → कर्नाटक युद्धे

• १७५७ → प्लासीची लढाई
